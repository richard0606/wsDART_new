# 调参指南（串口 / USB 网络）

> 不用浏览器、不用 ROS、不用 SSH。PC 上跑 `python3 tools/tune.py`，出中文菜单，跟着点就行。
> 给非技术人员（机械组/外宣都能用）。
>
> 硬件有三种接法，**任选一种**，效果完全一样。

## 0. 三种通道，怎么选

| 通道 | 需要什么 | 板子配置 | 适合 |
|------|---------|---------|------|
| **A. USB 网络**（推荐） | 一根 **Type-C 数据线** | `tune_port: tcp:8766` | 手上只有一根 Type-C 线，最省事 |
| **B. USB-TTL 串口** | 一个 USB-TTL 转接头 + 三根线 | `tune_port: /dev/ttyACM1` | 已经有 USB-TTL，想要最稳 |
| **C. 板载串口** | 一根 USB-TTL 接到排针 UART | `tune_port: /dev/ttyS1` | 不想占用 USB 口 |

> 调参通道和下位机 MCU 的 `/dev/ttyACM0` 是**分开的**，可以同时插着，比赛时也能随时连电脑调参。
> 万一两个参数填成了同一个设备，程序会**直接拒绝启动调参**并打错误日志，绝不会往 MCU
> 视觉协议链路上发调参指令。

### A. USB 网络（推荐）

1. 板子的 **Type-C / OTG 口**接 PC（**必须是数据线**，别用只供电的充电线）。
   ⚠️ 别用接相机的 USB-A 口；也别用 Type-C 口给板子供电。
2. PC 上会多出一个网卡：
   - **Windows**：设备管理器里出现 RNDIS USB 网卡，网卡名可能是"以太网 3"之类
   - **Linux**：多出 `usb0` 或 `cdc_ether` 网卡
3. 给这块网卡填上 **192.168.55.1 / 子网掩码 255.255.255.0**（板子固定是 192.168.55.2）。
4. 板子已经配好开机自启（`dart-usb-network.service`）。插线后想手动确认：

```bash
sudo tools/setup_usb_network.sh up      # 启用并配地址
sudo tools/setup_usb_network.sh status  # 看是否真的连上（carrier=1）
```

`status` 里 `carrier=1` 才算真连上了；`carrier=0` 说明线没插、或者线不支持数据。

### B. USB-TTL 串口

- 接线：USB-TTL 的 **TX → 板子 RX**、**RX → 板子 TX**、**GND ↔ GND**。
  （若你的 USB-TTL 只有 A/B 两个标注口，那它多半是数据口，需要三线；VCC 一般不用接。）
- 插上后板子上会出现 `/dev/ttyACM1`（第二个口，第一个 `/dev/ttyACM0` 给 MCU）。
- **没插 USB-TTL 也不影响比赛**——服务每秒自动重试，插上即用。

## 1. 板子侧配置

`src/yq_dart_aim/config/params.yaml`，三选一：

```yaml
tune_port: tcp:8766       # A. USB 网络（默认走这个最省事）
# tune_port: /dev/ttyACM1  # B. USB-TTL 串口
# tune_port: /dev/ttyS1     # C. 板载硬件串口（排针）
tune_baud: 115200         # 只有串口通道用得上
```

**留空 = 关闭调参**（比赛时可以关掉省事）。

启动日志里应出现对应的一行：

```
串口调参服务已启动: tcp:8766 @ 115200 baud（PC 端用 tools/tune.py）
串口调参服务已启动: /dev/ttyACM1 @ 115200 baud（PC 端用 tools/tune.py）
```

没插线/没插 USB-TTL 都不影响比赛——服务每秒自动重试，插上即用。

## 2. PC 端使用

```bash
pip install pyserial          # 串口通道需要；纯网络通道不用装
# 拷贝 tools/tune.py 到 PC
python3 tools/tune.py
```

- **通道 A（网络）**：直接跑，工具自动连 `192.168.55.2:8766`。
  PC 网卡不通就手动指定：`python3 tools/tune.py --net 192.168.55.2`
- **通道 B/C（串口）**：直接跑，工具自动找口（Linux 优先 `/dev/ttyACM1`；Windows 按 COM 编号从小到大）。
  找不到就手动指定：`python3 tools/tune.py --port COM5`（Windows）或 `--port /dev/ttyACM1`（Linux）。

菜单：

```
1) 查看全部参数      4) 加载预设
2) 修改参数          5) 保存到板子（重启保留）
3) 实时监控瞄准误差   6) 重新连接串口
                     q) 退出
```

菜单里所有提示都是中文，还带这个参数"怎么调"的说明。改参数时也可以直接输中文标签
（比如输入"曝光"会模糊匹配到曝光时间）。

**一键命令模式**（写脚本/批量用）：

```bash
python3 tools/tune.py list                  # 列出全部可调参数
python3 tools/tune.py get p_err             # 读一个
python3 tools/tune.py set p_err 8.5         # 改一个（立即生效）
python3 tools/tune.py save                  # 写入板子 params.yaml
python3 tools/tune.py watch                 # 持续看瞄准误差
python3 tools/tune.py load match_day        # 加载"比赛模式"预设
python3 tools/tune.py --port COM5           # 指定串口（Windows）
python3 tools/tune.py --net 192.168.55.2    # 指定走网络
```

> ⚠️ 不要把 `--port` 指到 `/dev/ttyACM0`，那是下位机 MCU 的口。
> 填错了板子也会拒绝启动调参并打错误日志。

## 3. 两个关键概念：生效 vs 保存

| 操作 | 效果 |
|---|---|
| `SET`（菜单 2 修改参数） | **立即生效**，但只改运行时内存 |
| `SAVE`（菜单 5 保存） | 把当前值**写进 `params.yaml`**，重启才保留 |

菜单里如果有未保存的修改，会显示 `* 有修改未保存！选 5 保存，否则重启会丢`。
**比赛前务必 SAVE 一次。**

保存时：
- `params.yaml` / `camera_params.yaml` 只替换对应那一行的值，**注释和排版原样保留**
- 原文件自动备份为 `.bak`（万一改错了可以拷回来）

## 4. 能调哪些参数

| 分组 | 参数 | 说明 |
|---|---|---|
| HSV 颜色阈值 | h_min/h_max, s_min/s_max, v_min/v_max | 传统模式的目标颜色筛选 |
| 形态学处理 | morph_kernel_size, morph_dilate_kernel_size | 去噪、连接断裂 |
| 目标筛选 | max_area | 面积过滤 |
| 瞄准与偏移 | p_err, offset_y, offset_0_0 ~ offset_2_3 | 误差缩放 + 12 个偏移量 |
| 相机参数 | exposure_time, gain | 曝光和增益（自动转发到 hik_camera 节点） |
| 模型识别 | use_model, conf_threshold, model_input_*, model_default_target, model_result_max_age_ms | 模型模式开关与阈值 |
| 系统与调试 | crop_*, use_serial, publish_*, enable_record | 裁剪、串口、调试输出、录制话题 |

**相机参数是跨节点的**：调参服务会自动通过 ROS 服务转发给 `hik_camera` 节点，
所以不用管它在哪个进程里。如果相机节点没起，会明确报"相机节点不可达/响应超时"。

参数元数据（名称/范围/中文说明）定义在 `include/yq_dart_aim/param_registry.hpp`，
是**唯一数据源**——PC 端只负责显示，不抄一份默认值（原来 web_tuner 那份抄本早就和
`params.yaml` 脱节了：曝光写 300、实际 50000）。

## 5. 预设

`config/presets/*.yaml` 里的参数集，可用菜单 4 加载：

- `match_day`（比赛模式）：串口开、调试图开
- `debug`（调试模式）：串口关、调试图开

预设也可以自己加：新建 `config/presets/xxx.yaml`，里面写 `参数名: 值`，
下划线开头的行（`_label` 等）会被忽略。加完重启 `dart_aim_node` 就能在菜单里看到。

**注意**：加载预设只改运行时，和改参数一样，需要 `SAVE` 才落盘。

## 6. 协议（自己写工具时用）

两种通道用的是**同一套协议**——串口发字节、TCP 发字节，命令格式完全一样。

ASCII 行命令（`\n` 结尾），应答一行 JSON。

| 命令 | 应答 |
|---|---|
| `PING` | `{"ok":true,"proto":1,...}` |
| `LIST` | `{"ok":true,"params":[{name,label,group,desc,type,min,max,node,value},...]}` |
| `GET <名>` | `{"ok":true,"name":..,"value":..}` |
| `SET <名> <值>` | `{"ok":true,...}` 或 `{"ok":false,"error":"超出范围..."}` |
| `SAVE` | `{"ok":true,"saved":true}` |
| `PRESETS` | `{"ok":true,"presets":[...]}` |
| `LOAD <名>` | `{"ok":true,"preset":..}` |
| `STATUS` | `{"ok":true,"mode":..,"target_class":..,"aim_err_x_px":..,...}` |
| `HELP` | 命令列表 |

在 PC 上用 Python 几行就能对接：

```python
# 串口通道
import serial
s = serial.Serial("/dev/ttyACM1", 115200, timeout=1)
s.write(b"SET p_err 8.5\n")
print(s.readline().decode())
```

```python
# 网络通道（不用装 pyserial）
import socket
s = socket.create_connection(("192.168.55.2", 8766), timeout=1)
s.sendall(b"SET p_err 8.5\n")
print(s.recv(4096).decode())
```

## 7. 排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 菜单里提示没找到口 | USB-TTL 没插好 / 驱动没装 | `ls /dev/ttyACM*` 确认；换 USB 口试试 |
| 串口打开了但板子没响应 | 插错口（插到 MCU 那个了）、波特率不对 | 用 `--port` 指定；确认板子上服务在跑 |
| 网络通道连不上 | 网线不是数据线 / PC 网卡地址没填对 / 用错 USB 口 | `sudo tools/setup_usb_network.sh status` 看 `carrier` 是否为 1；PC 网卡填 `192.168.55.1/24` |
| 提示 tune_port 和 usart_port 是同一个设备 | 两个参数填成了同一个口 | 调参换用 `tcp:8766`、`/dev/ttyACM1` 或 `/dev/ttyS1` |
| Type-C 口插上电脑没反应 | 用了只供电的充电线 | 换一根确认能传数据的线 |
| 中文显示乱码 | 终端编码 | `export LANG=C.UTF-8` 或用 Windows 终端改 UTF-8 |
| 改相机参数报"不可达" | `hik_camera` 节点没运行 | 起完整 launch（含相机） |
| 参数改了重启就丢 | 没 `SAVE` | 菜单 5 保存 |
| 保存后想撤销 | 原文件被备份 | `cp xxx.yaml.bak xxx.yaml` 再重启节点 |

## 8. 与旧 web 调参的关系

`web_tuner`（Flask + SocketIO + 1138 行前端）已整体删除。调参能力完全由串口通道承担，
且参数元数据收进 C++ 单一数据源。相关清理：`CMakeLists.txt` 不再安装 web_tuner、
`start.launch.py` 去掉 `web_tuner` 相关启动参数、`rm_watch_dog.sh` 去掉 web_tuner 拉起与监控。
